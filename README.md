# SmartCampusAPI

## Build and Run

### Prerequisites
- Java 8
- Maven
- Apache Tomcat 9
- NetBeans (recommended)
- Postman (recommended for testing)

### Technology Stack
- JAX-RS (Jersey)
- Maven Web Application
- Apache Tomcat 9
- In-memory Java data structures (`ConcurrentHashMap`, `ArrayList`)
- No Spring Boot
- No database

### How to Run
1. Open the project in NetBeans.
2. Make sure Apache Tomcat 9 is configured as the server.
3. Clean and build the project.
4. Run the project.
5. Open the API in a browser or Postman using:


http://localhost:8080/SmartCampusAPI/api/v1
